# Cómo publicar este repositorio en GitHub Pages

## 1. Crear el repositorio

Nombre sugerido:

- `propuesta-julio-hector-iusi`

Descripción sugerida:

- `Dashboards y base técnica sobre la propuesta de reforma tributaria inmobiliaria asociada al IUSI`

## 2. Subir el contenido

Sube **todo el contenido interno** de esta carpeta al repositorio:

- `index.html`
- `.nojekyll`
- carpetas `dashboards/`, `docs/`, `data/`, `scripts/`
- `README.md`
- `metodologia.md`
- `publicar_en_github_pages.md`

## 3. Activar Pages

En GitHub:

1. entra a `Settings`
2. entra a `Pages`
3. en `Build and deployment` selecciona:
   - `Deploy from a branch`
   - branch `main`
   - folder `/ (root)`
4. guarda

## 4. URL esperada

La URL quedará con una estructura similar a:

- `https://TUUSUARIO.github.io/propuesta-julio-hector-iusi/`

## 5. Recomendación de uso público

Comparte preferiblemente la portada:

- `index.html`

Desde ahí las personas pueden navegar al dashboard general, al radar municipal y a los documentos metodológicos sin entrar directamente a los archivos internos.
